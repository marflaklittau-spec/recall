🚀 部署与配置指引 ›
  1. 创建仓库：在 GitHub 新建一个 公开 仓库，把 index.html 上传进去。
  2. 修改配置：编辑 index.html 中的 CONFIG.repo，改成 你的用户名/仓库名（默认分支若不是 main，同时修改 CONFIG.branch）。
  3. 开启 Pages：仓库 Settings → Pages → Source 选择 main 分支 → Save。约 1 分钟后通过 https://用户名.github.io/仓库名/ 访问。
  4. 创建 photos 目录：打开 https://github.com/用户名/仓库名/upload/main/photos 上传任意一张照片，目录即自动创建，回忆墙开始工作。

💡 回忆墙通过 GitHub 公开 API 读取仓库 photos/ 目录，访客无需登录即可浏览； 上传需要 GitHub 账号 —— 你自己（仓库主人）在上传页可直接提交、立即上墙； 其他访客提交时 GitHub 会自动帮他们 Fork 并发起 Pull Request，由你审核合并后上墙。 文件名建议按 日期_作者_标题.jpg 命名，回忆墙会自动解析展示；发布弹窗会为带独白的照片生成同名 .json 独白/留言文件链接。

🚀 发布到回忆墙

照片将提交到 GitHub 仓库，合并后对所有人可见。整个过程约 1 分钟。

  1. 复制建议的文件名

    回忆墙会按「日期_作者_标题」自动解析展示（可选步骤，不改也能上墙）。

  2. 打开 GitHub 上传页，拖入照片

    可在页面上点铅笔图标把文件重命名为建议名称。

    打开上传页 ↗

    🕯️ 同步发布独白（可选）

    下面为每张带独白的照片生成配套 JSON 文件，打开后内容已自动预填，直接 Commit 即可。公开后，其他人可以为这段独白留言。

  3. 填写提交说明并提交

    把说明粘贴到 Commit changes 的输入框里，点击 Commit changes。

  4. 等待合并上墙

    若你是仓库主人，提交后立即上墙；若提示无写入权限，GitHub 会自动 Fork 到你的账号，提交后点击「Create pull request」发起合并请求，仓库主人审核通过即可在回忆墙看到。没有 GitHub 账号？免费注册一个。
